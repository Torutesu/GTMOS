# GTMOS — 事業計画

> 一言で
> Select グループ全事業のフルスタック GTM(Go-To-Market)を横軸で担い、
> その知見を国内外の顧客へ外販していく事業。
> 「世界をハックする」機能をグループ内に一つ持ち、順次プロダクト化して売る。

---

## 1. なぜやるか

- グループに複数事業(ShogunAI / AI 総戦研)や新規事業があり、各々が GTM を必要としている。
- 事業ごとにバラバラに外注・自前でやるより、**横断の GTM 機能を一つ持つ方が速く・強い**。
  - 学習が一箇所に溜まる。同じ失敗を各社が繰り返さない。
  - 人材・ツール・データの固定費を分散できる。
  - 立ち上げのたびにゼロから体制を組む時間がゼロになる。
- そのケイパビリティは**そのまま外販できる**。グローバル展開も同じ機能で走る。
- 差別化 = **AI ネイティブ × グローバル知見 × フルスタック**。従来の代理店とは別物。

### 従来の代理店と何が違うか

| | 従来の代理店 | GTMOS |
| --- | --- | --- |
| 範囲 | 単機能(戦略 / 広告 / 動画のいずれか) | 戦略〜獲得〜ブランド〜動画まで一気通貫 |
| 立場 | 受託。事業の外側 | 自社グループで実際に市場を獲っている当事者 |
| 実行速度 | 人月に比例 | AI ネイティブ。実行がボトルネックにならない |
| 市場 | 国内中心 | グローバル先行、国内は後 |
| ブランド | キャンペーン単位の消費 | 複利で効く「資産」として設計・蓄積 |

## 2. 事業モデル(二層構造)

### Layer 01 — Group GTM(内部)

グループ各社の立ち上げ〜グロースを横断支援する。**実戦の場であり R&D**。

- 対象:ShogunAI、AI 総戦研、および新規事業。
- ここで「型」を作る。うまくいった打ち手はテンプレ化し、次の事業に 1 日で展開する。
- 内部でやるので、施策の意思決定から数値までフルアクセスできる。
  これは外部の代理店には構造的に手に入らない解像度。

### Layer 02 — GTM as a Service(外部)

内部で磨いた「型」を国内外クライアントへ提供する。

- Layer 01 が先行し、Layer 02 が後追いする。**内製で証明されていないものは売らない**。
- 順次プロダクト化する(型 → テンプレート → 再現可能なサービス → 一部はツール化)。

```
  ┌─────────────────────────────────────────┐
  │  Layer 01 : Group GTM(内部)             │
  │  ShogunAI / AI総戦研 / 新規事業           │
  │  → 実戦・R&D・型の生成                    │
  └────────────────┬────────────────────────┘
                   │ 検証済みの「型」だけを外に出す
  ┌────────────────▼────────────────────────┐
  │  Layer 02 : GTM as a Service(外部)      │
  │  グローバル → 国内                        │
  └─────────────────────────────────────────┘
```

## 3. 提供サービス(3 本柱)

### 3.1 マーケ支援 / Full-stack Marketing

フルスタックの GTM 設計〜実行。

- 戦略:ポジショニング、ICP、価格・パッケージ、ローンチプラン
- 獲得:チャネル設計、広告、アウトバウンド、コミュニティ、PLG
- コンテンツ:メッセージング、LP、記事、SNS、ドキュメント
- 運用:計測基盤、ダッシュボード、週次の改善サイクル

**売り**:戦略屋・広告屋・動画屋の間で発生するハンドオフのロスがゼロ。

### 3.2 ブランドキャピタル / Brand Capital

ブランドを消費するコストではなく、**複利で効く「資産」**として設計・蓄積する。

- ブランド × 資本の視点。短期の獲得効率だけで意思決定しない。
- 「何を積み上げているのか」を明文化し、施策をそこに紐づける。
- 創業者・事業のナラティブ設計を含む(採用・資金調達にも効く)。

### 3.3 ローンチ動画 / Launch Video

プロダクトローンチを「勝たせる」ための動画。世界に届く一本を作る。

- 単発の制作ではなく、ローンチ設計の一部として作る。
- 参考:The Launch Video Company

## 4. ターゲット / 順序

1. **グローバル**(先行)
   - AI ネイティブ × グローバル知見という差別化が最も効く市場。
   - 単価が高く、フルスタックで発注できる相手を探している層がいる。
2. **国内**(後追い)
   - グローバルでの実績を持ち帰る形で入る。「海外の勝ち筋の翻訳」が刺さる。

内部(Group GTM)は最初から並走する。順序の話は外販先の優先順位。

---

## 5. 体制

- **フルスタックで回せる事業責任者 1 名(コア)**
  - 戦略から実行まで自分で回せることが必須要件。
  - Layer 01 で型を作る主体でもある。
- **以降は業務委託で可変にスケール**
  - 固定費を持たず、案件と内部需要に応じて伸縮させる。
  - AI ネイティブ前提なので、人数の増やし方が従来の代理店と違う
    (人月を売らない。実行量は AI 側で伸ばし、人は判断と品質に寄せる)。

## 7. ロードマップ(案)

| フェーズ | 内容 | アウトプット |
| --- | --- | --- |
| Phase 0 | 器を作る | ドメイン取得、LP 公開、資料、問い合わせ導線 |
| Phase 1 | Layer 01 を回す | グループ 1〜2 事業で GTM を実装。型と数値を作る |
| Phase 2 | 最初の外販 | グローバル数社。3 本柱のうち入口を 1 つに絞って売る |
| Phase 3 | 型のプロダクト化 | テンプレート / チェックリスト / 一部ツール化 |
| Phase 4 | 国内展開 | グローバル実績を持ち帰る形で国内へ |
